# Screenshot Evidence

Place final graduation-project screenshots in this folder.

Use these filenames:

| Screenshot | Filename |
| --- | --- |
| Login/register or wallet connection | `01-login-register.png` |
| Patient dashboard | `02-patient-dashboard.png` |
| Patient upload/metadata controls | `03-patient-upload.png` |
| Record access modal | `04-access-modal.png` |
| Doctor accessible records | `05-doctor-records.png` |
| Diabetes prediction result | `06-prediction-result.png` |
| Institution dashboard | `07-institution-dashboard.png` |

Rules:

- Use fake sample records only.
- Use Sepolia test wallets only.
- Do not show private keys, seed phrases, real patient data, or secret environment values.
- Crop screenshots only enough to remove browser clutter; keep the page content visible.
